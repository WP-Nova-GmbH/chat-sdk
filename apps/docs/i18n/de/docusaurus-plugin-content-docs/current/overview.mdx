# Nova Chat SDK

<p className="nova-lede">Bette den Nova-Assistenten in jede Website ein und verbinde ihn mit deinem eigenen DOM. Das SDK liefert die iframe-Hülle, Token-Erneuerung, Seiten-Snapshots, Navigationsaktionen und Integrator-Tools, während dein Backend das Secret schützt.</p>

## Übersicht

Das Nova Chat SDK ist das Browser-Paket, das ein von Nova gehostetes Chat-iframe in eine kundeneigene Seite einbindet. Es ist bewusst schlank: Das SDK steuert den Launcher, den iframe-Container, die Token-Übergabe und die `postMessage`-Bridge. Das iframe steuert die Konversationsoberfläche und kommuniziert mit Nova-Diensten über ein kurzlebiges Embedded-Session-Token.

Der Browser erhält niemals ein Integrations-Secret. Deine App stellt einen `tokenEndpoint` bereit, der den aktuellen Benutzer authentifiziert, Nova serverseitig über `POST /embed/session` aufruft und die Embedded-Session-Antwort an das SDK zurückgibt.

Die SDK-Bridge verarbeitet drei Fähigkeiten der Host-Seite:

- Seiten-Snapshots, die sichtbaren Text, Links, Bedienelemente, Labels, Auswahl und sichere Feldwerte zusammenfassen.
- Eingebaute Navigationsaktionen gegen stabile Element-Handles aus dem neuesten Snapshot.
- SDK-definierte Integrator-Tools, die deine App mit dem vollständigen Vertrag
  und Handler über `registerTool` registriert. Die Surface-Einstellung
  „Page Tools“ ist nur die serverseitige Freigabe.
- Serverseitige Backend-Tools und automatische `research-and-compose`-
  Workflows über `pageWorkflows`, die erst nach exakter Seiten-Readiness starten.

Nova kann zusätzlich `request_user_input` als interaktive Auswahlkarte im
iframe anzeigen. Dieses Conversation Tool und die eingebauten Seitenaktionen
werden nicht im Host registriert.

## Laufzeitmodell

1. Ein Nova-Admin erstellt eine Embedded Chat Surface und konfiguriert Origins,
   Page Reading, Page Navigation und Page Tools.
2. Das Backend hält das Secret und stellt einen `tokenEndpoint` bereit.
3. Die Seite ruft `WpNova("init", { publicSurfaceId, tokenEndpoint })` auf.
4. Das SDK mountet `<wp-nova-chat>`, authentifiziert das iframe und überträgt
   Snapshots, Routen und registrierte Tool-Spezifikationen.
5. Nach Seitenaktionen wartet das SDK auf eine gerenderte Zielansicht, bevor es
   einen neuen Snapshot sendet.
6. Ein unbekannter Benutzer bleibt in `existing_only` unverfügbar; eine
   bestätigte JIT-Surface kann mit einem zweckgebundenen Creation-Token eine
   aktive Mitgliedschaft anlegen.
